# 怎么选模型：能力、价格、速度、开源闭源、国内外

对应页面：[怎么选模型：能力、价格、速度、开源闭源、国内外](https://study.ainiya.de/agent/llm-choose-model.html)

“在自己的题上量”的最小示范：8 条告警分 4 类（GC / 数据库 / 支付 / 前端），4 条正则做基线，本机两个开源小模型各分类一遍，比正确率和耗时。只用标准库。

## 准备

需要 [llm-next-token](../llm-next-token/README.md) 的 Qwen2.5-0.5B（8090）和 [llm-reasoning-thinking](../llm-reasoning-thinking/README.md) 的 Qwen3-0.6B（8091，`--jinja`）两个服务。

## 怎么跑

```bash
cd agent
uv run python llm-choose-model/main.py
```

## 预期输出

2026-11-22，2 核 ARM，llama.cpp b12618，温度 0，Python 3.13：

```
===== 基线：4 条正则，不用模型 =====   正确 8/8，每条不到 1 毫秒
===== Qwen2.5-0.5B =====             正确 4/8，平均每条 0.5 秒（认不出的都答 GC）
===== Qwen3-0.6B（不思考） =====      正确 2/8，平均每条 0.3 秒（8 条全答“数据库”）
```

正则是照着这 8 条写的，换一批告警就会漏；这正是“评测集太小、照着答案写”的反例。

## 练习

1. 再写 8 条换了说法的告警，不改正则，看规则还能对几条。
2. 改成“规则判出来就用规则，判不出再调模型”，统计落到模型上的比例。
3. 把系统提示里类别的顺序改成“前端、支付、数据库、GC”，看 0.5B 的偏向会不会跟着变。
