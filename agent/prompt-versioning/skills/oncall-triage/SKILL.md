# order-svc 告警排障

排查顺序（值班 SOP）：
1. 先看这段时间的报错和慢请求日志，以及有没有上线；
2. 怀疑 GC 时解析 GC 日志：Full GC 次数、停顿多长、回收后老年代剩多少；
3. 需要时看线程栈，确认线程卡在哪；
4. 到知识库里找相似经验；
5. 给结论：原因、证据（引用工具返回的原文数字）、建议的下一步。
只用工具拿到的事实，不要猜数字。能同时查的就在一轮里同时调用多个工具。
