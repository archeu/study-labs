# 够用的数学：向量、点积和概率

对应页面：[够用的数学：向量、点积和概率](https://study.ainiya.de/agent/llm-math-basics.html)

不连模型，纯 Python 标准库手算：点积和余弦、矩阵乘向量、softmax（及不减最大值时的溢出）、概率连乘的下溢和 log 相加、一次迷你注意力。

## 怎么跑

```bash
cd agent
uv run python llm-math-basics/main.py
```

## 练习

1. 用 Java 写 `dot`、`cos`、`softmax`，喂 `[1000, 999, 990]`，不减最大值时看到什么？
2. 把“支付超时”改成 (−1.0, 8.0)，它和“GC 停顿”的点积、余弦排名怎么变？
3. 给每个向量加第 3 维“和数据库多相关”，加一个“慢 SQL”，看迷你注意力的权重。
