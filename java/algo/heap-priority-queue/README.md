# 堆和优先队列：订单簿按价格排队，最优价 O(1) 看、O(log n) 进出

对应页面：[堆和优先队列：订单簿按价格排队](https://study.ainiya.de/algo/heap-priority-queue.html)（算法基础第 6 课）

## 怎么跑

- IDE：打开仓库的 `java/pom.xml`，运行 `labs.algo.heap_priority_queue` 包下的 main。
- 命令行：`cd java && mvn -q -pl algo/heap-priority-queue compile exec:java -Dexec.mainClass=labs.algo.heap_priority_queue.<类名>`
- 类：`PriceHeap`（手推）、`OrderBook`（撮合）、`HeapPitfalls`（坑）、`AlgoFunctions`（常用函数速查）、`HeapBench`（测速）。
- `HeapBench` 别在 Maven 进程里跑，编译后直接起 JVM：`java -Xms1g -Xmx1g -cp algo/heap-priority-queue/target/classes labs.algo.heap_priority_queue.HeapBench`，约 4 分钟。

## 练习

先猜结果，再运行。

1. 加撤单（懒删除）：`Order` 加 `cancelled`，撤单只打标记，`match` 里 peek 到已撤的就 poll 掉。撤掉 B2 后，S2 第一笔成交的对手应是 B3。
2. 删掉 `BID` 的 `thenComparingLong`，挂 8 张同价买单再来一张能全吃的卖单，看成交顺序。
3. 买簿换成 `TreeMap<Long, ArrayDeque<Order>>`（降序），撮合输出应该一模一样，比较器不再需要 `seq`。
4. Top K：100 万笔随机成交额，用大小为 10 的小顶堆找最大的 10 笔，和排序结果对比。
