# 贪心：每一步只拿眼前最好的，什么时候不会后悔

对应页面：[贪心：每一步只拿眼前最好的，什么时候不会后悔](https://study.ainiya.de/algo/greedy.html)

## 怎么跑

- IDE：打开仓库的 `java/pom.xml`，运行 `labs.algo.greedy` 包下的 main。
- 命令行：`cd java && mvn -q -pl algo/greedy compile exec:java -Dexec.mainClass=labs.algo.greedy.<类名>`
- 类：`Greedy`（不限次数 / 只许一次买卖、暴力对拍、手续费和面额 {1,3,4} 两个反例）、`BacktestSlots`（区间调度四条排序规则和 2ⁿ 暴力对拍一万组）。

## 预期输出

2026-11-21，2 核 Neoverse-N1 虚机，OpenJDK 17.0.21，`--release 8` 编译。

```
不限次数（贪心）= 14，暴力枚举 = 14
只许一次 = 10
对拍 2000 组：贪心和暴力不一致 0 组
手续费 2，价格 [1, 3, 2, 8, 4, 9]：朴素贪心 = 7，暴力 = 8
面额 {1,3,4} 凑 6：贪心 3 枚 [4, 1, 1]，最优 2 枚
随机 10000 组：最早开始 2934、最短的先排 379、冲突最少 13、最早结束 0
```

## 练习

先猜结果，再运行。

1. 打印每一笔买卖点，连续上涨合成一笔（⑤ 的价格输出 3 笔）。
2. “冲突最少”出错时打印那组任务，手画它错在哪。
3. 会议室：最少几台机器排下所有任务（用 `PriorityQueue`），⑤ 的 7 个任务答案是 2。
