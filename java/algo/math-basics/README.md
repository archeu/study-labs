## 练习

先猜结果，再运行。

1. **安全的中点**：加一个 `mid(lo, hi)`，分别用 `(lo+hi)/2`、`lo+(hi-lo)/2`、`(lo+hi)>>>1` 三种写法，用 lo = 1.5×10⁹、hi = 2×10⁹ 测。只有第一种得到负数。
2. **位数对拍**：写 `digits(long n)`，用循环除以 10 求位数，再和 `(int)(Math.log(n)/Math.log(10)) + 1` 对拍所有 10 的幂（10⁰～10¹⁸）。应该看到 7 个算错的数。
3. **组合数取模**：把 `comb` 改成杨辉三角 DP（C(n,k) = C(n−1,k−1) + C(n−1,k)），每步对 1e9+7 取模，算 C(1000, 500) mod 1e9+7。
