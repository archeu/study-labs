# 动态规划入门：状态和转移，带手续费的买卖为什么贪心不行

对应页面：[动态规划入门：状态和转移，带手续费的买卖为什么贪心不行](https://study.ainiya.de/algo/dp-basics.html)

## 怎么跑

- IDE：打开仓库的 `java/pom.xml`，运行 `labs.algo.dp_basics` 包下的 main。
- 命令行：`cd java && mvn -q -pl algo/dp-basics compile exec:java -Dexec.mainClass=labs.algo.dp_basics.<类名>`
- 类：`StockDp`（带手续费的买卖：纯递归 / 记忆化 / 递推表 / 两个变量、调用次数、对拍；冷冻期三状态和更新顺序写错；36 万点耗时和记忆化栈溢出）。

## 预期输出

2026-11-21，2 核 Neoverse-N1 虚机，OpenJDK 17.0.21，`--release 8` 编译。

```
第 19 课朴素贪心 = 7
纯递归 = 8，调用 127 次
记忆化 = 8，调用 23 次
n=25：纯递归调用 67108863 次，记忆化 99 次
冷冻期 [1, 2, 3, 0, 2]：三状态 = 3，暴力 = 3，原地更新顺序写错 = 4
36 万个分钟价：两个变量 4 ms，结果 593166
记忆化递归：StackOverflowError
```

## 练习

先猜结果，再运行。

1. 从递推表倒推买卖点，[1,3,2,8,4,9] 应输出 0 买 3 卖、4 买 5 卖。
2. 最多 2 笔：[3,3,5,0,0,3,1,4] 答案 6。
3. 分段预热缓存，让记忆化在 36 万天上不栈溢出。
