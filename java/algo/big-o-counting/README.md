# 大 O 是怎么数出来的

对应页面：[大 O 是怎么数出来的：操作次数、最坏和平均、摊还与 log n](https://study.ainiya.de/algo/big-o-counting.html)

## 怎么跑

- IDE：打开仓库的 `java/pom.xml`，运行 `labs.algo.big_o_counting` 包下的 main。
- `Count`（只数次数，不计时，任何机器输出都一样）：`cd java && mvn -q -pl algo/big-o-counting compile exec:java -Dexec.mainClass=labs.algo.big_o_counting.Count`
- `Doubling`（双倍法计时；别在 Maven 进程里跑，直接起 JVM）：编译后 `java -Xms2g -Xmx2g -cp algo/big-o-counting/target/classes labs.algo.big_o_counting.Doubling`

## 练习

先猜结果，再运行。

1. 在 `Count` 里加 `for (i = 1; i < n; i *= 2) for (j = 0; j < i; j++) ops++;`：O(n log n) 还是 O(n)？（n 翻倍，次数也只翻倍：1 + 2 + 4 + … < 2n）
2. 在 `Doubling` 里加 `ArrayList.remove(0)` 和 `ArrayDeque.pollFirst()` 两种清空写法，n 从 5 万翻倍到 40 万：比值各接近几？（4 和 2）
3. 给 `grow` 加初始容量参数，传 n：搬运和扩容次数变成多少？（都是 0）
